# Easy Party 🎉

لعبة حفلات عربية RTL تعمل كتطبيق PWA بدون مكتبات أو Build، مصممة وفق المواصفات الشاملة للمشروع.

## التشغيل
افتح `index.html` عبر GitHub Pages أو أي خادم ملفات ثابت. لا يوجد backend.

## GitHub Pages
Settings → Pages → Deploy from branch → `main` / `/ (root)` ثم Save.

## التقنيات
Vanilla JS ES Modules، localStorage، WebAudio API، Vibration API، Service Worker.

## ملاحظات
المشروع يعمل أوفلاين بعد أول تحميل، والحفظ محلي على الجهاز. جميع نصوص الواجهة عربية وRTL.
