# Easy Party

لعبة حفلات عربية تعمل بالكامل على جهاز واحد، مبنية بـ HTML وCSS وVanilla JavaScript ES Modules، وتدعم PWA وRTL والحفظ المحلي.

## التشغيل
1. افتح `index.html` عبر خادم محلي أو GitHub Pages.
2. لا توجد مكتبات أو خطوة build مطلوبة.
3. على GitHub Pages اختر `main` كمصدر النشر من إعدادات Pages.
4. ثبّت اللعبة من متصفح الهاتف باستخدام إضافة إلى الشاشة الرئيسية.

## اللعب
- من 1 إلى 4 لاعبين على نفس الجهاز.
- جلسة كاملة: جاسوس + تحدي 5 ثواني + ألعاب مصغرة.
- بطولة الألعاب المصغرة.
- تدريب فردي.
- متجر، اقتصاد، XP، إنجازات، مهام، مكافأة يومية وعجلة حظ.
- تصدير واستيراد الحفظ بصيغة JSON.

## الخصوصية
لا يوجد خادم للبيانات؛ الحسابات المحلية والحفظ يستخدمان `localStorage`.
